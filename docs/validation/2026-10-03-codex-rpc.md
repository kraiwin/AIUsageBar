## Review และ regression

Independent reviewer ตรวจ protocol/tests/project integration แบบ read-only; final ไม่พบ blocker เพิ่มใน offline scope
แก้สอง findings ก่อนปิดงาน:

1. matching quota response ตามด้วย notification ใน chunk เดียวต้องไม่ทิ้ง success; one-shot return completion ทันที ทิ้ง bounded remainder และให้ transport ปิด child/pipe
2. result ไม่มี quota keys ต้องเป็น invalidQuota ไม่ใช่ไม่มีข้อมูล; null/ไม่มี weekly ที่ schema รองรับยังเป็น no-data

Tests ตรวจ outbound allowlist, fragmented JSONL, strict correlation/type, quota reply ก่อน outbound return, timestamps/freshness, malformed envelope, errors ที่ไม่เก็บข้อความบัญชี, server requests, byte/line limits, EOF และ terminal state
`verifiedFreshFetch` ต้องมีหลักฐานจาก transport/CLI ก่อนใช้; default เป็น unverified snapshot ไม่ใส่ observation เวลาอ่านไฟล์
