## กรณีที่ครอบคลุม

เปอร์เซ็นต์ 0/100/ทศนิยม, NaN/Infinity/out-of-range, numeric boolean, null/field/type ผิด, unsupported/missing weekly duration, duplicate windows, explicit Codex bucket identity, reset timestamp และ JSON ผิด
แยก receivedAt/providerObservedAt, snapshot ที่ไม่ยืนยัน freshness, stale/expired/invalid timestamps, repeated snapshots, per-provider isolation และ retained data หลัง failure
UI presentation ซ่อน invalid/expired quota และคงป้าย failure/snapshot ตามจริง; fixture numbers อยู่เฉพาะ tests ไม่ปรากฏใน store เริ่มต้นของแอป

## Independent review

Reviewer ตรวจแบบ read-only และพบ timestamp-invalid retained quota ที่กลับมาแสดงหลัง loading/failure
แก้โดยใช้ evaluator เดียวกันทุกเส้นทาง พร้อม transition regression test; reviewer ตรวจซ้ำยืนยันแก้แล้ว
เพิ่ม guard ไม่รับ explicit bucket identity ของผลิตภัณฑ์อื่นเป็น Codex; reviewer ตรวจ guard/tests แล้วไม่พบ blocking issue
Reviewer ไม่ได้รัน tests เอง; ผล execution ข้างต้นเป็นของ main agent

## ตรวจ app bundle ปกติ

- `codesign --verify --deep --strict` ผ่าน
- ตรวจ signed entitlements: มีเฉพาะ `com.apple.security.app-sandbox=true`; ไม่มี network, get-task-allow หรือ filesystem read exception
- `LSUIElement=true`, version 0.1.0; version/build number มาจาก App.xcconfig
- local ad-hoc signing เพื่อเปิดในเครื่อง; Xcode ไม่เปิด hardened runtime ให้ ad-hoc build นี้ จึงไม่อ้างว่า notarize หรือ hardened runtime ผ่านแล้ว
- XCTest Debug host ถูก Xcode ฉีดสิทธิ์สำหรับ test manager/read-only filesystem; แยกจาก bundle ปกติและไม่ส่งมอบเป็นชุดทดลอง

## UI/lifecycle smoke — ยังไม่ครบ

- เปิด Debug shell ผ่าน Launch Services สำเร็จและตรวจพบ process ของ executable ใน workspace
- ปิดเฉพาะ Debug shell ที่เราเปิดไว้ แล้วเปิด app bundle ปกติใน Release สำเร็จ
- ตรวจพบ process ของ executable ใน Release หลังเปิด; ยังทำงานอยู่ ไม่ได้สรุปว่า UI ผ่านจากการมี process เพียงอย่างเดียว
- Computer Use เชื่อมกับ Mac เดิมได้ แต่ `getApp` ของแอป Menu Bar ที่ไม่มีหน้าต่าง timeout; ยังไม่ได้เห็น popup จริง
- ขอผู้ใช้คลิกไอคอนสามแท่งเพื่อเปิด popup แล้วตรวจต่อ; ยังไม่รับรองการใช้ keyboard, popup rendering, VoiceOver หรือปุ่ม quit จาก runtime จริง
- การหยุด Debug process เป็นการเปลี่ยนชุดทดลอง ไม่ใช่หลักฐานว่าเมนู quit ผ่าน
- LSUIElement ยืนยันจาก bundle; การไม่มี Dock icon ยังต้องตรวจด้วย UI จริงประกอบ

## สิ่งที่ยังไม่ทำ

ไม่มี account/usage smoke, token access, network endpoint, polling, Claude bridge install, CLI-managed auth หรือการแก้ global settings
ยังไม่ทดสอบบน macOS 14/Intel, ยังไม่ทำ performance validation ของ integration, ไม่ publish/push/release จากงานนี้
